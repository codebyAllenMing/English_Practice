安全設計

機密管理

  • Anthropic API key 存 macOS Keychain,config.json 永不落地明文
  • config.json 權限 600;舊明文 key 首次讀取自動搬遷

供應鏈與完整性

  • 模型下載 SHA256 釘檔驗證,不符即清除
  • Cargo.lock / package-lock 進版;npm audit + cargo-audit 稽核
  • ONNX / GGUF 為純資料格式(無 pickle 類程式碼執行面)

執行面防護

  • 所有 folder 參數過 validate_folder(防路徑跳脫)
  • 嚴格 CSP 白名單;webview 不載入任何遠端內容
  • TaskGuard 防長任務重入;AI 呼叫無工具、structured outputs 硬約束(prompt injection 影響被鎖死)
